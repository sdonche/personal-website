Fourteen Perspective components the platform never shipped.

2026-09-22 · 6 min read · Ignition

Calendar views become iframes. Admin screens shove operators back into gateway config. Touch panels fight the double-keyboard problem. Editable grids get rebuilt per project and drift. I have watched the same four fights on more Perspective jobs than I care to count.

Perspective Components is fourteen free Apache-2.0 components under one palette category. Drag, bind, stay inside Perspective scripting, theming and security. No trial. No activation key.

What is in the palette

  • Scheduling. Resource Timeline and Calendar / Scheduler with drag, resize and recurrence.
  • Data entry. Editable Data Grid, Date/Time Range Picker with live rolling windows, Color Picker, On-Screen Keyboard.
  • Views. Pan & Zoom View, Branching Diagram for lineage and routing.
  • Editors. Rich Text and Code / JSON editors.
  • Admin family. Schedule, Roster, User and Holiday managers. The pieces Vision had and Perspective never got.

Components fire events. They do not rewrite your bound data behind your back. Colours follow the active Perspective theme. UI text ships in seven languages, with per-string overrides when you need them.

Free, with a floor

Not a paid SKU. Not a Vision port either. Ignition 8.3.6+. If you need professional support or a component that is not in the set, talk to Mustry.

Signed .modl on GitHub or the product page. No licence key.
